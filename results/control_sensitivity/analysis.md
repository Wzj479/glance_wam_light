# 记录动作的时序敏感性实测

一条匹配抓取示范；固定初始状态、随机种子和 10 步稳定等待；9 个条件均执行 136 个控制周期（20Hz，6.8 秒）。

| --- | --- | ---: | ---: |
| baseline | 是 | 125.85 | 12.13 |
| all_delay_1 | 是 | 125.76 | 12.29 |
| all_delay_2 | 是 | 126.42 | 11.91 |
| all_delay_4 | 是 | 125.40 | 12.80 |
| gripper_delay_1 | 是 | 124.26 | 11.04 |

| gripper_delay_4 | 是 | 113.43 | 11.75 |
| hold_2 | 是 | 126.08 | 12.18 |
| hold_4 | 是 | 124.83 | 12.47 |

本次未满足最终任务谓词的条件：无。

所有频率、延迟和时间轴均为仿真时间；CPU 回放不要求实时执行。
整体动作延迟是固定动作流的起始时移；没有模型、观测延迟或在线重规划。
动作保持重复同一条增量命令，控制器仍每 50ms 更新目标；它不等于保持绝对位姿，也不等于执行多个不同动作组成的 WAM 动作块。
一个条件只跑一条示范；重渲染的视频用于检查物理状态一致性，不构成新增独立评测回合。
视频对照左侧为 baseline，右侧为 gripper_delay_4。
使用 CPU texture1024 诊断资产，不是原始视觉基准成绩。
