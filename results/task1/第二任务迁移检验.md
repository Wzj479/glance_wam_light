# 第二任务迁移检验：task 1 = put_the_bowl_on_the_stove

## 目的

检验 task 08 上发现的「过早松爪」机理与在线夹爪规则，能否迁移到第二个抓取放置任务。

## 方法

- 任务：LIBERO-Goal **task 1**（`put_the_bowl_on_the_stove`），抓取物仍是 `akita_black_bowl_1`，放置目标是固定家具 `flat_stove_1`（据 bddl 与 `obj_body_id` 确认；目标无 object 包装，故 driver 新增 `--grasp-body/--target-body` 支持）。
- 初态：init 0–9（协议 `protocols/protocol_task1_{a,b}.json`），base 权重，color_strong。
- 官方成功由 LIBERO goal 检查 `(On akita_black_bowl_1 flat_stove_1_cook_region)` 给出（env `done`）。
- 在线规则同 task 08：首次闭爪后，累计闭爪未满 `min_closed_steps` 就抑制张爪。
- **每个臂重复 5 次**（同初态、同协议、同 seed，独立服务器进程与仿真回合；GPU 非确定性使回合产生不同动作轨迹），按 task 08 的翻转率口径统计，不采信单次读数。

## 结果（5 次重复）

| 臂 | 单次 | 5 次重复合计 |
|---|---|---|
| base | 2/10 | **10/50（=2.0/10）** |
| 规则 `min_closed_steps=50` | 6/10（单次偏乐观） | **27/50（=5.4/10）** |

逐回合成功次数（x/5）：

| 回合 | base | 规则 N=50 | 判定 |
|---|---|---|---|
| ep0 / ep4 | 5/5 / 5/5 | 5/5 / 5/5 | 基线成功，**零副作用** |
| ep6 / ep7 / ep9 | 0/5 | **5/5 / 5/5 / 5/5** | **稳定救回** |
| ep2 | 0/5 | 1/5 | 翻转，**不可靠** |
| ep3 | 0/5 | 1/5 | 翻转，**不可靠** |
| ep1 / ep5 / ep8 | 0/5 | 0/5 / 0/5 / 0/5 | **未救回** |

> **单次读数 6/10 高估了**：ep2 的那次成功只是 1/5 的翻转。重复后真实增量是 **2.0/10 → 5.4/10**，且**集中在 ep6/7/9 三个稳定救回**；ep2/ep3 是不可靠翻转，ep1/ep5/ep8 修不了。base 侧 10/50 完全稳定（两个成功回合 5/5、其余 0/5），说明 task 1 的 base 失败是稳定的、可逐回合归因。

## 机理迁移：成立

按「首次闭爪后连续闭合帧数」看（base）：

- 成功 ep0/ep4：首次闭爪 ~36–37，**连续闭合 56 步**（接触 47/56 帧）；
- 失败 8 个：首次闭爪 36–44（**时机与成功相近**），但**只连续闭合 2–14 步**就张开。

与 task 08 同构：不是「闭太早」，而是**闭合后没持住**（task 08 成功持 32–34、失败 11–20；这里成功持 56、失败 2–14）。

## 规则迁移：部分成立，稳定救回 3 个

- **稳定救回 ep6/ep7/ep9（各 5/5）**，对两个基线成功回合**零覆盖、零副作用**。
- ep2/ep3 只在 5 次里各成功 1 次（翻转），不能算修复。
- **未救回的 ep1/ep5/ep8** 在 N=50 下已经**强制闭爪 50–53 步、接触 40+ 帧**（确实抓住并持住了），仍然失败——失败发生在更下游（放置/滑移），不是松爪时机。与 task 08 的 **state 35** 同类。

## 结论

1. **「过早松爪」机理跨任务迁移成立**：第二个抓取放置任务上仍是主失败模式，且 base 失败稳定可归因。
2. **在线规则可迁移但更弱**：真实增量 **2.0/10 → 5.4/10**，稳定救回 3/8（ep6/7/9），零副作用；单次的 6/10 是翻转造成的乐观读数。
3. **残留是另一类失败**：抓住并持住仍失败，指向放置/滑移；规则边界因此更清楚，且与 task 08 的 state 35 一致。

## 边界（如实声明）

- 第二个任务、单一 suite、base 权重、color_strong、10 个初态、**5 次重复**。
- 未跨 checkpoint、未跨条件；阈值只测了 30 与 50，未做完整平台扫描。
